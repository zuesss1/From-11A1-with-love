# From 11A1 with love

Dự án làm để học cho vui :)))

Xem trực tiếp: https://zuesss1.github.io/From-11A1-with-love/

## Tính năng
- Đếm ngược rồi bắn pháo hoa trên canvas với 6 kiểu nổ (tròn, hai màu, lấp lánh, lá rủ, tách hạt, vòng tròn).
- Chạm/click vào màn hình để tự bắn pháo.
- Tự xoay ngang khi điện thoại/tablet cầm dọc.
- Chạy cùng tốc độ trên màn hình 60/90/120/144Hz, giới hạn số hạt để không giật trên máy yếu.

## Tuỳ chỉnh
- Mặc định đếm demo 5 giây. Sửa `CONFIG.targetDate` trong `index.html` (ví dụ `'2027-01-01T00:00:00+07:00'`)
  hoặc thêm vào URL: `?to=2027-01-01T00:00:00%2B07:00` để đếm ngược tới thời điểm thật.
